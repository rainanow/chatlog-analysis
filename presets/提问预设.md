# 聊天记录整理 · 预设指令

> 用法：把 `【...】` 里的内容替换成你的实际情况，整段复制发给 AI。
> 方括号里的斜杠是「选一个」，删掉不用的。

---

## 通用尾巴（建议每次都带上）

```
输出要求：
- 不要表格，不要小标题，不要分点罗列
- 按时间顺序连续叙述，事件用整段话写
- 时间戳不用标，除非时间差本身有意义（比如犹豫、沉默、隔了很久才回）
- 只写事实，不写评价和总结，不要出现"沟通策略""情绪疏导"这类词
- 如果是你的推测，单独标出来
```

这段是前面几轮返工换来的，直接贴上能省掉大部分来回。**如果只能记一样，就记这段。**

## 预设 1 · 快速回忆

**用在**：第二天想快速回到昨晚发生了什么。

```
帮我整理这段聊天记录。
用途：我想快速回忆发生了什么，不用给别人看。
我关心：事实经过，特别是关键转折点。

【粘贴记录】

输出要求：（贴上面的通用尾巴）
```

**产出**：一份连续叙述的事件稿，无评价、无结论。

## 预设 7 · 还原一次吵架（跨多天）

**用在**：吵完了，想知道到底是怎么起来的、又是怎么过去的。

**注意**：这个预设不看单日记录。**吵架通常跨 2–4 天，而且最激烈的部分和"和好"的部分不在同一天。** 单贴一天的记录一定会漏掉开头或结尾。

```
帮我还原一次吵架。
用途：我想搞清楚它是怎么起来的、怎么升级的、又是怎么过去的。
我是【我方称呼】，对面是【对方称呼】。

时间范围：【起止日期，比吵架本身前后各多一天】

请按这个顺序整理：
1. 吵架前一天的正常状态（我想知道它是不是突然的）
2. 起因那句话是哪一句
3. 从哪句话开始性质变了（这个最重要）
4. 升级过程中双方各自重复最多的话是什么
5. 谁先松口的、用什么方式
6. 什么时候恢复日常话题的
7. 事后有没有人回头再提  ← 单独写一段

另外请单独列出来（没有就写"无"）：
- 全程没有被回答的问题
- 说出来的新事实（之前没出现过的信息）
- 说了又被收回/反悔的决定
- 中途出现的第三方名字

【粘贴记录】

输出要求：（贴上面的通用尾巴）
```

**产出**：一份按"起因→转折→升级→收尾→事后"顺序的连续叙述，外加末尾四份清单。

## 三个坑

**别只说"总结一下"。**
"总结"会触发提炼主题、归纳要点、给结论的默认模式，产出的是议论文，不是备忘。说"整理"或"记录"。

**格式偏好一开始就说。**
放在第一轮，别等我先做错再返工。格式属于"怎么交付"，和"要什么内容"一样重要。

**先说用途，再贴记录。**
用途决定了后面所有取舍。用途说不清，我给的必然是四平八稳的通用稿——也就是你第一轮拿到的那种。

---

## 四个坑（吵架专用）

**必须给前一天的记录。**
吵架前一天通常是正常的。**"前一天正常"本身就是重要信息**——它说明这场架不是累积爆发，是被某一句具体的话点着的。只贴吵架当天，会把"点火"误读成"早就憋着"。

**必须给和好之后那一天的记录。**
最容易被漏掉的一天。**两个人在这一天说了什么、没说什么，比吵架本身更能说明问题。** 我这次能找到"21 日早上 8:18 主动回收"，靠的就是多贴了一天。

**把"没有被回答的问题"单独拎出来。**
吵架里双方都在说，但**问句和答句经常对不上**。那些问了没人答的问题，通常正是真正卡住的地方。这个靠感觉找很容易漏，得专门列一遍。

**说了又反悔的决定要单独列。**
吵架结束时的"承诺"未必是真的结局。**如果中间没有出现过改口的讨论，那这个改动就是无声发生的**——无声发生的改动，事后最容易被当成"本来就是这样"。
